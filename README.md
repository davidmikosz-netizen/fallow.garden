# fallow.garden 🌱
> **A tool to help restore your focus.**

In agriculture, leaving land fallow is how soil naturally regenerates vital nutrients. In human cognition, intentional zero-input downtime is how the prefrontal cortex recovers from directed attention fatigue.

`fallow.garden` is a lightweight, zero-tracking, single-file web application designed to counteract algorithmic attention fragmentation using peer-reviewed cognitive neuroscience and Attention Restoration Theory (ART).

---

## Features

### 1. Educational Research Deck
* Explores the mechanisms of screen fatigue, variable dopamine schedules, micro-task switching, and attention residue.
* Synthesizes findings from Dr. Gloria Mark, Dr. Sophie Leroy, Dr. Maryanne Wolf, and Stephen & Rachel Kaplan.
* Includes a deck randomizer for discovering fresh insights on return visits.

### 2. Behavioral Triggers ("When to Deploy")
* Identifies six subtle indicators of cognitive depletion (e.g., *The Glaze & Loop*, *The Phantom Check*, *Micro-Tab Sprees*, *Friction Avoidance*).

### 3. Interactive Recovery Protocols
* **3-Minute Optical Soft Reset:** Guided visual expansion orb to relax ciliary eye muscles and panoramic peripheral vision.
* **5-Minute Zero-Input Rest:** Minimalist timer with on-demand synthesized brown noise (soft wind) to activate the Default Mode Network (DMN).
* **15-Minute Nature Walk:** Randomized observational prompts for off-screen nature immersion.
* **Native Audio Engine:** Harmonic chimes (432 Hz) and brown noise synthesized dynamically via the Web Audio API—no external MP3 assets or audio files required.

### 4. The Open Loop Catcher
* A session-based buffer to offload fleeting thoughts, errands, or search urges without breaking cognitive flow.
* Automatically resets when the app session closes.

---

## Tech Stack & Design Philosophy

* **Zero Dependencies:** Pure vanilla HTML5, CSS3 (Custom Properties), and modern JavaScript.
* **Privacy-First:** Zero trackers, zero cookies, zero external API calls, zero analytics.
* **Ultra-Lightweight:** Self-contained in a single file (`index.html`) for instant loading and offline capability.

## Deployment

Deploy anywhere as a static website:

### Vercel / Netlify
Push `index.html` to a GitHub repository and link it to your Vercel or Netlify dashboard.

### GitHub Pages
1. Push `index.html` to the root of your repository.
2. Go to **Settings > Pages**.
3. Set the source branch to `main` (or `master`) and directory to `/ (root)`.
4. Configure your custom domain (`fallow.garden`) in the custom domain settings.
